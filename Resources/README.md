# Resources

This folder contains source resources used by the native app.

| File | Purpose |
| --- | --- |
| `OpenBridge.entitlements` | macOS capabilities used by application builds |
| `OpenBridgeAppIconSource.svg` | editable app icon source |
| `OpenBridgeIcon.icns` | generated app icon |
| `OpenBridgeMenuBarSource.jpeg` | editable menu-bar artwork |
| `OpenBridgeMenuBarTemplate.png` | generated macOS template icon |

The corresponding Swift package resources are under `Sources/OpenBridgeApp/Resources/`. These OpenBridge brand assets are reserved; see `docs/governance/TRADEMARK_AND_ASSET_POLICY.md`.
