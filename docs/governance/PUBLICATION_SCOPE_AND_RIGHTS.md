# Publication scope and rights

The public repository contains application source and contributor build/test inputs only. Website source, signed distribution operations, app/DMG files, model weights, generated runtimes, private history, secrets and internal release evidence are excluded from every reachable public Git object and GitHub artifact.

Project-authored code and documentation use Apache-2.0. Third-party resources retain their upstream licences. Included Openbridge marks/artwork remain reserved Lunr Studio assets; see [asset policy](TRADEMARK_AND_ASSET_POLICY.md). Use synthetic or appropriately licensed test data.

Source publication requires a reviewed exact candidate, passing source checks, rights/privacy review and maintainer approval. A source build does not prove microphone permissions, model inference, paste behavior, official signing or a full clean-contributor journey. Report those checks separately.
