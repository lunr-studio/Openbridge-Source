# Sources

This folder holds the Swift source code for the native macOS app.

Swift Package Manager expects this folder name by convention. That is why it stays at the repo root.

| Folder | What it is for |
| --- | --- |
| `OpenBridgeApp/` | The actual menu bar app code. |

Beginner note: source code is the human-written recipe. The build turns it into an app you can run.
