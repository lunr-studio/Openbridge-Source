# Source Helper Scripts

These helpers support source development and testing.

| File | Purpose |
| --- | --- |
| `generate_app_icon.sh` | Regenerate app icon resources from the project-owned source artwork. |
| `openbridge_help_review_server.py` | Preview and test the local Help content during development. |
| `test_history_store_permissions.swift` | Check history and permission-related storage behaviour. |
| `test_custom_dictionary_store.swift` | Check custom dictionary persistence. |
| `test_spoken_formatting_commands.swift` | Check deterministic spoken-formatting transforms. |
| `test_v1_v2_compatibility.swift` | Check that older local data remains readable. |

There are no official packaging, signing, notarization, upload, or distribution scripts in this repository.
